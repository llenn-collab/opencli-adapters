## Scope decisions

- The adapter keeps the existing OpenCLI command surface and JSON output. `ask` now returns its conversation ID and can continue through the website UI; no second MCP service or wrapper is justified by the current CLI.
- Conversation continuation uses Qwen's visible composer and stored history. No direct or undocumented write endpoint is used; live continuity awaits a nonempty assistant response.
- UI selection of a mode is documented separately from successful mode execution.
- Attachment permission failures are attributed to the browser bridge based on where the operation failed; no upstream rejection was observed.

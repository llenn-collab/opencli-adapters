## Scope decisions

- The adapter keeps the existing OpenCLI command surface and JSON output. No second MCP service or wrapper is justified by the current CLI.
- Conversation continuation and management writes are deferred because this checkout has no verified request contract for them. The visible UI alone is not enough evidence to invent endpoints.
- UI selection of a mode is documented separately from successful mode execution.
- Attachment permission failures are attributed to the browser bridge based on where the operation failed; no upstream rejection was observed.
